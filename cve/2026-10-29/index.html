VMware ESX / ESXi

Wie al beheerder is op de host, kan sommige acties uitvoeren zonder dat ze in de logs komen. De score is laag, maar een spionagegroep gebruikte dit begin 2026 om zijn sporen te wissen, en sinds 28/10 staat het lek op de CISA KEV-lijst. De patch bestaat al sinds juli.

  • Cloud Foundation 5.2 → 5.2.4

Linux-kernel (Fragnesia)

CVE-2026-46300

Een gewone gebruiker of een binnengedrongen webapplicatie kan root worden op de server. Sinds 28/10 staat het lek op de CISA KEV-lijst. Volgens een onderzoeksrapport werd het samen met PHP2Shell gebruikt om servers over te nemen.

  • Kernel-update van je distributie installeren (Debian, Ubuntu, Red Hat, SUSE, AlmaLinux, Amazon Linux) en herstarten
  • Kernels van vóór 13 mei 2026 zijn kwetsbaar
  • Nog niet kunnen updaten? Tijdelijk de modules esp4, esp6 en rxrpc uitschakelen (breekt IPsec-VPN op die machine)
  • PHP ook bijwerken: zie PHP2Shell in de briefing van 28/10

Oracle E-Business Suite

CVE-2026-101767

Zonder login kan een aanvaller via een SQL-injectie code laten uitvoeren op de server. Op 27/10 zagen onderzoekers de eerste aanvalspogingen op hun lokservers. Een geslaagde aanval is nog niet gemeld.

UEFI-firmware (EDK II, netwerkboot)

CVE-2026-97631

Wie in hetzelfde netwerk zit, kan een server die via het netwerk opstart (PXE) laten crashen en in theorie code laten uitvoeren nog vóór Secure Boot. Een fix bestaat in de broncode, maar firmware-updates van de fabrikanten zijn er nog niet. Misbruik is niet bekend.

  • PXE-/netwerkboot uitschakelen in de BIOS/UEFI als je het niet gebruikt
  • Netwerkboot alleen toelaten in een apart, afgeschermd netwerk
  • Firmware-updates van je serverfabrikant opvolgen; nog niet alle fabrikanten hebben gereageerd
